# 停車須知・點餐入口

客人掃描座位上的 QR code 後，會先看到停車須知，確認愛車停放位置後，再點「開始點餐」進入 simpos 點餐系統，並自動帶入該座位。

網頁網址：https://raaay522.github.io/parking/

## 運作方式

每個座位的 QR code 都連到同一個網頁，只是網址最後面帶的座位資訊不同：

| 參數 | 說明 | 範例 |
|---|---|---|
| `seat` | 座位名稱，需與 simpos 後台完全相同 | `seat=隔板3` |
| `seatMap` | 座位區，沒有填寫時預設為「內用」 | `seatMap=戶外` |

範例：

- 內用 隔板3：`https://raaay522.github.io/parking/?seat=隔板3`
- 戶外 窗邊：`https://raaay522.github.io/parking/?seat=窗邊&seatMap=戶外`

網頁會讀取這兩個參數，把「開始點餐」按鈕換成對應座位的 simpos 點餐連結，並在頁面底部顯示座位名稱。網址沒有帶座位時，按鈕會連到不指定座位的菜單。

## 目前的座位

**內用（18 個）**

吧台1～8、包廂、高吧1～2、摺疊、角落、隔板1～3、外帶、備用

**戶外（8 個）**

吧台、吧台2、吧台3、吧台4、二樓、小房間、小圓桌、窗邊

> 內用和戶外都有「吧台2～4」，名稱相同，靠座位區區分。貼 QR code 時請注意標示的座位區。

## 新增或修改座位

網頁不需要修改，只要產生新的 QR code：

1. 確認 simpos 後台的座位名稱與座位區名稱（一字不差）。
2. 依上方格式組出網址；內用座位可省略 `seatMap`。
3. 用該網址產生 QR code，掃描測試確認點餐系統顯示的座位正確後再列印。

## 修改停車說明

停車規則文字在 `index.html` 的各個 `<section>` 區塊中；照片放在 `img/` 資料夾。修改並上傳到 `main` 分支後，GitHub Pages 約 1～2 分鐘會自動更新網頁，已印好的 QR code 不需重做。
